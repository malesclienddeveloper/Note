# fankit-dl scan di Kaggle

1. Buat dataset Kaggle baru, upload folder ini (atau zip) sebagai dataset `fankit-dl`.
2. Buat Notebook baru, attach dataset tersebut.
3. Settings → Internet ON.
4. Jalankan cell berurutan di `fankit-scan.ipynb`.
5. Download `manifest.zip` dari Output.
6. Ekstrak, salin `manifest.json` ke Termux `~/storage/shared/coc_assets/`.
7. Di Termux jalankan download+kompres seperti biasa.
